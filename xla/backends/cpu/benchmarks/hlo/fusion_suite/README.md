# XLA:CPU fusion benchmark suite

174 unoptimized HLO modules for evaluating XLA:CPU fusion and cost-model
changes. They come from JAX libraries and hand-written kernels in physics,
optimization and ML. None contain custom calls: LU, triangular solve and
Cholesky are lowered to plain HLO (`gen/no_lapack.py`). Metadata and
stack-frame tables are stripped.

| directory | modules | what |
|---|---|---|
| `pairwise/` | 58 | Pairwise N-body style reductions and their gradients (gravity, Coulomb, Biot-Savart, RBF, min distance, sum of distances), reductions over rows and columns in several dtypes, multi-consumer fusion cases. Generated by `gen_hlo.py`-style JAX snippets, sizes in the file names. |
| `libs/` | 44 | Library workloads: equinox, flax, torax, DESC, jax-fem, diffrax, jax-md, ott-jax, raytrax, brax/MJX, jaxlie, exponax, jraph, Kuramoto RK4/RK8, plain-JAX ML blocks. See `libs/README.md`. |
| `val/` | 16 | Held-out set: optax, blackjax, optimistix, lineax, distrax, dynamax, jraph and plain JAX. See `val/README.md`. |
| `val2/` | 22 | Second held-out set: haiku, numpyro, jax.scipy, BCOO, simulation and image kernels. See `val2/README.md`. |
| `fieldline/` | 8 | Biot-Savart field-line tracing (RK4 in a while loop) and the single field evaluation. Three source layouts: naive, `aos` ([N,3] arrays; `soa` is the old name of the same module) and `soaplanar` (six [N] arrays). |
| `biot_savart_cpp/` | 14 | Biot-Savart forward and VJP of a coil set, f64, N = 8 ... 10240 sources and targets, written to match a hand-written C++ implementation. |
| `micro/` | 7 | k tiny dependent kernels in a while loop, for per-kernel dispatch overhead. |
| `scale/` | 5 | A Gemma-like bf16 residual stream with L = 4 ... 64 layers (`gen_residual.py`), for compile-time scaling. |

`gemma3_1b_flax_call` and `gemma4_2b_bf16`, also used in the evaluation,
already live in `../` and `../../huge_hlo/`. `val/lineax_gmres_f32` is left
out: it crashes the compiler at HEAD.

Run one module:

```
bazel run -c opt //xla/backends/cpu/benchmarks:hlo_benchmark_test -- \
  --hlo_paths=$PWD/xla/backends/cpu/benchmarks/hlo/fusion_suite/libs/exponax_ks2d_rollout.hlo \
  --hlo_paths_absolute --benchmark_filter=all
```

`BM_HloModule` measures the run time, `BM_CompileHloModule` the compile time.

The generator scripts are in `gen/`. Each writes to `$OUT` (default: the
current directory). The library versions are listed in the per-directory
READMEs.
